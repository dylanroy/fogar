How it works

Look it up, then answer from what came back.

Tick the box

“Search the web first” sits under the ask box. Tick it for one question, or set it to start ticked in Settings. The free provider is already chosen.

off by default · one click

Fogar searches

Up to five results. Their titles and snippets go in front of your question, numbered, with an instruction: answer only from these, cite them like [1], and say so if the answer is not there.

snippets, not whole pages

Read, then check

The answer cites its sources inline. The list of links appears only when the answer actually cites something; otherwise the line under the answer says “no relevant web results” or “none cited”.

sources are links · open them
More ways in

When the first answer is not enough, or the question starts on a page.

Dig deeper

One menu on every answer

Search the web and answer again, with sources. Think longer, which lets the local model reason first with a 600-token budget. Or ask the other model, if you have set one up: your cloud model if the answer came from the device, the device if it came from the cloud. The better answer replaces the first in the conversation.

Right-click

“Ask Fogar about …”

Select text on any page and right-click. A new tab opens and asks about it, and the page comes along: its title, address, and about 1,500 characters around your selection. The answer comes from the page, and says when the page does not contain it. Dig deeper adds web results on top.

With a file attached, the answer comes from the file and the search rests. Dig deeper can still add the web, as a supplement. About attachments.

Straight talk

Not a search engine.

Every mode, and what it sends. See the ledger.

  • The free search is thin. It knows well-known people, places, and topics. It does not know news, prices, or niche sites. For those, add a Brave Search or Tavily key.
  • The model reads snippets, a few hundred characters per result, not the pages. A question the snippets do not answer gets “I could not find it in the results”, if the model behaves.
  • A small model can still misread a source. The citation is there so you can check it in one click.
  • Five results, one pass. It does not crawl, follow links, or research for minutes. For a plain list of links, start with “?” or press Cmd or Ctrl+Enter and the question goes to DuckDuckGo instead.
Questions

Fair questions, short answers.

Is this a private Perplexity alternative?

For quick factual questions, it does the same basic thing: search, then answer with citations. It is much smaller. It reads five snippets, not whole pages, and the answer is written by a model in your browser or by the cloud endpoint you chose. No Fogar server sees the question.

Do I need an API key?

No. The free provider uses DuckDuckGo’s Instant Answer API and Wikipedia, with no key. A Brave Search or Tavily key adds full web results, and both have free tiers.

Is anything searched without my asking?

No. A search happens only for a question you send with “Search the web first” ticked, or when you choose “Search the web and answer again” from Dig deeper. The box starts unticked unless you change that in Settings.

What does the search provider see?

A query and, for Brave or Tavily, your key. The free provider gets the subject of your question with the question words stripped. None of them gets your conversation, an attached file, or the text of a page you right-clicked on.

Why are some answers missing a source list?

The list appears only when the answer cites a result. If the model found nothing useful, the line under the answer says how many results were fetched and that none were cited, so you know the search happened.

Install

Add to Chrome

Fogar is on the Chrome Web Store. One click to add it, and it updates itself from there. Then open a new tab.

Add to Chrome

Free, from the Chrome Web Store. Brave, Arc, and Edge install from it too.

On your phone, or not on Chrome? The same Fogar runs as a web app at app.fogar.ai. Open it once with a connection, add it to your home screen (Safari: Share, then Add to Home Screen; Chrome: the menu, then Add to Home screen), and set it up from there; after that it works offline. The widgets that need Chrome’s own APIs, Sessions, bookmarks, Inbox, Feed, Jira, and Agenda, stay on the desktop.

Loaded the zip before the listing went live? The store copy has a different extension ID, so your data will not follow on its own. Three steps move it over.

  1. In your current Fogar, open Settings and click Download a backup.

    Todos, notes, recipes, widgets, sessions, and settings go into one file.

  2. Add Fogar from the store.

    It opens on your next new tab, empty.

  3. Open its Settings and Restore from a backup.

    Once it looks right, remove the old copy in chrome://extensions.

Can't use the store? The same build is here as a zip: unzip it, turn on Developer mode in chrome://extensions, and Load unpacked. It will not update itself.
