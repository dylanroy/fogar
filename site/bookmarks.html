Bookmarks · a new tab for Chrome

Find the bookmark you half remember.

Start typing in the new tab and matching bookmarks appear underneath: by title, by site, by folder, with room for a typo. For the ones you cannot name, ask. “Find bookmarks about cooking” has a model on your device read the list and sort it. Your bookmarks never leave the machine.

Two ways in

Type when you know a word. Ask when you know a topic.

Typing

Ranked, not just matched

Chrome’s own bookmark search matches whole words at the start of a title or address. Fogar builds its own index once and ranks every bookmark against every word you type: title first, then site, then folder, then the rest of the address. Short typos in titles are forgiven.

Recent bookmarks get a nudge. So do short titles, which are usually the site itself rather than an article. Six words and up is a question, not a lookup, so the list steps aside and the model takes over.

Asking

Three passes, and the model cannot make it worse

Ask for a topic and Fogar first has the model expand it into related words, so “cooking” also looks for risotto, kitchen, and seriouseats. A keyword pass over titles, addresses, and folders then sets a floor no model can take away. Finally the model reads your list twenty-five bookmarks at a time and adds what words alone miss.

Results come back matched by both first, then by words, then the model’s own picks. Past five hundred bookmarks it re-reads only the keyword candidates, so a big collection stays quick.

Open tabs

With the Sessions widget on the page, the same keystrokes find tabs open in your other windows. One click brings the window forward and selects the tab.

Saved tabs

Closed last week, found today

Windows you saved and closed appear too, one click from reopening. That is the Sessions widget.

Everything else

Routing, not guessing

A URL opens. A question mark searches the web. “remind me” sets a reminder, “todo:” adds a todo, arithmetic is computed. Anything else goes to the model.

Keyboard

No mouse needed

Type, arrow down, Enter. Cmd or Ctrl and Enter always searches the web instead, whatever the box would otherwise do.

Straight talk

Chrome keeps the bookmarks. Fogar finds them.

The rest of Fogar is a new tab that answers from a model running in your browser. See what leaves in each mode.

  • Fogar is not a bookmark manager. Add, move, and organize in Chrome as you always have; Fogar reads the result.
  • The finder is only as good as your titles. A bookmark called “Untitled” with a cryptic address gives the model nothing to go on.
  • Asking takes seconds, not milliseconds: a small model reads twenty-five titles at a time. Progress is shown and you can stop it.
  • In Cloud mode the finder sends bookmark titles and sites to your endpoint, because that is where the model is. On this device, nothing leaves.
Questions

Fair questions, short answers.

Does it replace Chrome’s bookmark manager?

No. Chrome keeps the bookmarks and you organize them there as before. Fogar reads the tree, searches it as you type, and can remove the one bookmark you point at. The only thing it ever adds is a folder when you promote a saved session.

Can it delete a bookmark by accident?

Only the one you click × on, and only after you confirm. The finder never removes anything; it lists.

How does it handle typos?

Titles forgive small ones: the letters of a word four characters or longer only have to appear in order, not next to each other, so “fgar” still finds Fogar. Sites, folders, and addresses need an exact fragment.

How many bookmarks can it search?

The index is built once from Chrome’s bookmark tree and rebuilt when bookmarks change, so thousands are fine and typing stays instant. The finder has the model read everything up to five hundred bookmarks; above that it reads only the keyword candidates, so it stays quick on big collections.

Does the finder work in Cloud mode?

Yes, with your own key. Be aware of what that means: the titles and sites of your bookmarks are sent to the endpoint you typed, in batches, because that is where the model reading them lives. On this device, nothing is sent.

Why does the list vanish when I type a long question?

Six words and up is a question rather than a lookup, so the bookmark list steps aside and the question goes to the model. If you want the model to look through your bookmarks, say so: “find bookmarks about …” or “which bookmarks are job postings” routes to the finder.

Install

Add to Chrome

Fogar is on the Chrome Web Store. One click to add it, and it updates itself from there. Then open a new tab.

Add to Chrome Get the source

Free, from the Chrome Web Store. Brave, Arc, and Edge install from it too.

Loaded the zip before the listing went live? The store copy has a different extension ID, so your data will not follow on its own. Three steps move it over.

  1. In your current Fogar, open Settings and click Download a backup.

    Todos, notes, recipes, widgets, sessions, and settings go into one file.

  2. Add Fogar from the store.

    It opens on your next new tab, empty.

  3. Open its Settings and Restore from a backup.

    Once it looks right, remove the old copy in chrome://extensions.

Can't use the store? The same build is here as a zip: unzip it, turn on Developer mode in chrome://extensions, and Load unpacked. It will not update itself.
