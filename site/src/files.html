Straight talk

A small model reads a few pages, not a book.

The rest of Fogar is a new tab that answers from a model running in your browser. See what leaves in each mode.

  • On this device the model gets about 1,200 words, two or three pages, so its 4,096-token window still holds your question and its answer. Past that, only the start of the file is read, and the chip says so.
  • Scanned PDFs have no text layer. Fogar says so instead of guessing, and has no OCR in the ask box yet. The Notebook reads a photo of a page.
  • Images, spreadsheets, slides, and old .doc files are not read. Export a CSV or a PDF. Password-protected PDFs and files over 40 MB are turned away.
  • Finding a fact in text that is in front of it is something even the smallest tier did well in our tests. It can still be wrong. Check the figure before you sign anything.
  • In Cloud mode the file’s text goes to the endpoint you typed. On this device, nothing leaves.
Questions

Fair questions, short answers.

Is my file uploaded anywhere?

No. The file is read inside the new tab, with pdf.js for PDFs and an unzipper for Word files, both shipped inside the extension. On this device the model runs in your browser too, so nothing leaves. In Cloud mode the extracted text goes to the endpoint you chose, and nowhere else.

Why did it only read the first three pages?

The models on your device have a 4,096-token window shared by the instructions, the conversation, the file, and the answer. About 1,200 words of document fits with room to spare, so Fogar reads until that budget is full and the chip tells you where it stopped. Cloud mode takes 40,000 characters.

Can it read a scanned PDF?

Not yet. A scan is a picture of text with no text layer, and the ask box has no OCR. Fogar tells you the file is probably a scan rather than answering from nothing. The Notebook widget can turn a photo of a printed page into text on your device.

Does it work offline?

Yes, in Device mode once the model is cached. Reading the file and answering both happen in the browser, so there is nothing to connect to.

Is the file saved anywhere?

No. Its text is held in memory for the current conversation, so follow-up questions work. It is never written to extension storage or included in a backup. New conversation or closing the tab drops it.

What if the answer is not in the file?

The model is told to answer from the file, quote names and figures exactly as written, and say plainly when the file does not contain the answer. If only part of the file was read, it is told that too, so it can say the answer may be in pages it did not see.
