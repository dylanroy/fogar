How it works

Add the widget. Save. Forget, safely.

Add the Sessions widget

Add widget, then Sessions. Chrome asks for the tabs permission, which it labels “Read your browsing history”. Fogar reads the titles and addresses of open tabs, only while the widget is on the page, and never your history.

optional permission · asked once, when you add the widget

Save & close

One window, or every window except the one you are in. Duplicates collapse. The list of open windows doubles as a switcher: click a window’s name to bring it to the front.

named from the date and the top sites · rename any time

Find it again

Type in the widget’s search box, or in the ask box on any new tab, where saved tabs appear under your bookmarks as you type. Open hits switch; saved hits reopen.

open tabs first · then saved · one click either way
Straight talk

Not a tab manager.

The rest of Fogar is a new tab that answers from a model running in your browser. See what leaves in each mode.

  • It does not group, color, or suspend tabs. Chrome’s tab groups and memory saver already do that.
  • It does not snapshot on its own. You press Save. An automatic safety net is on the roadmap, not in the build, so this page does not claim it.
  • It does not sync. Sessions stay on this device. Export a bookmarks file, or promote a session to bookmarks and let Chrome’s own sync carry it.
  • It never reads incognito windows, and it skips browser pages such as chrome://settings and the new tab itself.
Questions

Fair questions, short answers.

Why does Chrome say “Read your browsing history”?

That is Chrome’s label for the tabs permission, the only way an extension can see the titles and addresses of open tabs. Fogar reads open tabs, not history, and only while the Sessions widget is on the page. The permission is optional: nothing else in Fogar asks for it.

Does saving a window close it?

Only if you choose “Save & close”. “Save” leaves everything open. “Save & close others” saves every window and closes all of them except the one you are in.

Do restored tabs all load at once?

No. The first tab loads. The others are created discarded, so they sit in the tab strip with their titles and cost almost no memory until you click one.

How many tabs can it hold?

Thousands. Sessions live in Chrome’s extension storage, and Fogar declares unlimitedStorage so a long history of saved windows never hits the default quota. Duplicate addresses inside one session are collapsed when you save.

Can I get my tabs out of Fogar?

Yes, three ways: a Markdown list, a bookmarks file that any browser imports from its bookmark manager, or a Fogar file that “Restore from a backup” brings back. Or promote a session straight into a bookmark folder. Nothing is locked in.

Does it sync between my computers?

No. Everything stays on this device. Export a bookmarks file and import it elsewhere, or bookmark the session and let Chrome sync the folder.

What about incognito windows?

Fogar never reads them. It also skips browser pages such as chrome://settings, extension pages, and the new tab itself, since those are not worth saving.

Install

Add to Chrome

Fogar is on the Chrome Web Store. One click to add it, and it updates itself from there. Then open a new tab.

Add to Chrome Get the source

Free, from the Chrome Web Store. Brave, Arc, and Edge install from it too.

Loaded the zip before the listing went live? The store copy has a different extension ID, so your data will not follow on its own. Three steps move it over.

  1. In your current Fogar, open Settings and click Download a backup.

    Todos, notes, recipes, widgets, sessions, and settings go into one file.

  2. Add Fogar from the store.

    It opens on your next new tab, empty.

  3. Open its Settings and Restore from a backup.

    Once it looks right, remove the old copy in chrome://extensions.

Can't use the store? The same build is here as a zip: unzip it, turn on Developer mode in chrome://extensions, and Load unpacked. It will not update itself.
